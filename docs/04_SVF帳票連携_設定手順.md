# SVF 帳票連携 設定手順

- **作成日**: 2026-10-19
- **対象**: SVF サーバー（Universal Connect/X）と ATOM の Web サーバー
- **目的**: ATOM から SVF へ帳票を出力できるようにするまでの設定手順を残す

> **この手順書は人間が実行してください。** AI エージェントは本番環境（DB / IIS / ファイルサーバ）へ直接操作を行いません。
> SVF サーバーは**他システムの本番環境**です。既存のジョブ・様式・`schema.ini` には触れないでください。

> **2026-10-19、本書の手順で PDF の出力まで確認済みです。**

---

## 1. 全体像

ATOM はテキストファイルを作って置くだけです。SVF がそれを拾って PDF にします。

```text
ATOM（ASP.NET）
  ① データベースから帳票データを取得
  ② 連携ファイル（txt）を生成
  ③ SVF サーバーの監視フォルダへ配置
          ↓ Universal Connect/X が 15 秒間隔で検知
     様式ファイル（.xml）へ流し込み
          ↓
     PDF を出力
  ④ ATOM が PDF を取得してブラウザへ返す
```

**Java の中継プログラムも DataSpider も使いません。**

### 関係するもの

| | 置き場所 | 作る人 |
|---|---|---|
| 連携ファイル（txt） | 監視フォルダ | **ATOM が自動生成** |
| ファイル定義（見出し付きサンプル） | 監視フォルダ | 人（初回のみ） |
| `schema.ini`（列定義） | 監視フォルダ | 人（初回のみ） |
| 様式ファイル（`.xml`） | 既存様式フォルダ | 人（帳票ごと） |
| ジョブ | Universal Connect/X | 人（帳票ごと） |

## 2. 環境

| 項目 | 内容 |
|---|---|
| 製品 | SVF Ver. 9.2（SVFX-Designer / SVF for PDF / Universal Connect/X） |
| サーバー | Web サーバーとは**別筐体**。他システムの帳票で**本番稼働中** |
| 管理画面 | SVF サーバー上のブラウザで `localhost:44080` |
| 監視間隔 | **15 秒** |
| 文字コード | 「出力設定」の `SVF エンコーディング` が **MS932**（CP932） |
| 上書き | 「出力ファイルの上書きを行う」は **OFF** |

> **`SVFDATA` と `SVFDATA_KH` の 2 系統があります。**取り違えやすいので、
> Universal Connect/X のジョブ一覧に出ているパスを正としてください。

## 3. 連携ファイルの仕様

### 書式

```text
<start>
VrSetOutputPrinter="HONKAN_PRNT01"
VrSetUseReportDirector=1
VrSetDocName2="（ドキュメント名）"
<end>
見出し行（タブ区切り）
データ行（タブ区切り）
```

| 項目 | 値 |
|---|---|
| 文字コード | **Shift_JIS（CP932）** |
| 改行 | **CRLF** |
| BOM | **なし** |
| 区切り | **タブ** |

- `<start>` 〜 `<end>` が制御部。**SVF の API 関数名 = 値**を書く。文字列はダブルクォートで囲む
- 制御部の直後が**見出し行**、以降が**データ行**。**列数を一致させる**
- **見出し行の名前が、様式のフィールド名になる**
- 値にタブ・改行を含めない（列ずれ・行ずれの原因になる）

### 明細の持たせ方

**ヘッダー項目を明細行ごとに繰り返します。**

```text
伝票A / 明細1 / 配送先=X / 品目=…
伝票A / 明細2 / 配送先=X / 品目=…
伝票B / 明細1 / 配送先=Y / 品目=…
```

1 ファイルに複数伝票を入れ、**文書分割のキー**で PDF を分けます。

| 帳票 | 行数 |
|---|---|
| 配送手配書（定期便・定期便2・定期便3・AIR） | 1 伝票 1 行 |
| 日新入荷 | 同上 |
| 入荷明細書 | 明細ごとに 1 行 |

### ATOM 側の実装

`src/Atom.Report/SvfDataFileWriter.vb` が生成と配置を行います。

- 書き込み途中を SVF に拾われないよう、**`.writing` を付けた名前で書いてから改名**する
- 値のタブ・改行は半角空白へ置き換える
- 見出しと列数が合わなければ例外にする

## 4. 初回だけ行う設定

### 4-1. 監視フォルダを作る

**ATOM 専用のフォルダを作ります。**

```text
D:\SVFDATA\data_atom\
```

> **既存の `D:\SVFDATA\data\` には置かないでください。**
> そこの `schema.ini` は 63KB・30 セクション以上あり、本番が共用しています。
> 専用フォルダにすれば、既存の設定ファイルを一切編集せずに済みます。

### 4-2. ファイル定義を置く

**見出し行を持つサンプルデータファイル**を置きます。ジョブの「ファイル定義」に指定します。

```text
D:\SVFDATA\data_atom\定義AT00接続テスト.txt
```

中身は連携ファイルと同じ形式です（制御部＋見出し行＋データ行 1 件）。

### 4-3. schema.ini を置く

**ファイル定義と同じフォルダ**に置きます。テキストドライバ用の列定義です。

```ini
[定義AT00接続テスト.txt]
CSVDataFormat=other
CharacterSet=OEM
Col1="REF_NO" Char Width 20
Col2="MEMO" Char Width 40
Format=TABDELIMITED
MaxScanRows=10
SepHeadDetail=0
defencode=MS932
```

| キー | 意味 |
|---|---|
| セクション名 | **「ファイル定義」のファイル名。**データファイル名ではない |
| `Format` | `TABDELIMITED`（タブ区切り） |
| `CharacterSet` / `defencode` | `OEM` / `MS932`（CP932） |
| `Col<n>` | **見出し行と同じ名前を左から順に。**`Width` は最大長の目安 |

**セクション名がファイル定義のファイル名のため、ATOM が置くデータのファイル名は毎回変わって構いません。**

帳票を増やすときは、**このファイルにセクションを追記**します（ATOM 専用なので追記して問題ありません）。

### 4-4. Web サーバーからの書き込み権限

監視フォルダを共有し、**IIS のアプリケーションプールの実行アカウント**に書き込み権限を与えます。

実行アカウント名は `/Pages/Report/SvfConnectionTest.aspx` で確認できます。

> **手作業で置けても、アプリケーションからは書けない**ことがあります。必ずアプリから確認してください。

## 5. 帳票を 1 つ追加する手順

### STEP 1　様式を作る

SVFX-Designer で **XML 様式ファイル（`.xml`）** を作ります。

- **フィールド名を見出し行と一致させる**（ここが対応の鍵）
- 日本語を出す枠は**日本語フォント**にする
- 現行帳票の PDF を下地にできる
- 既存様式（`海外発注書.xml` など）の作りを参考にできる

**保存先は既存様式と同じフォルダ。**

> **新しいフォルダに置いてはいけません。**フルパスで指定しても
> `VrSetForm` が `RC=[-30]` で開けません（検索パスの外になるため）。
>
> **既存の様式ファイルは開かないでください。**新規作成だけで足ります。

### STEP 2　schema.ini にセクションを足す

`D:\SVFDATA\data_atom\schema.ini` に、その帳票のファイル定義のセクションを追記します。

### STEP 3　ファイル定義を置く

見出し行を持つサンプルを `D:\SVFDATA\data_atom\` へ置きます。

### STEP 4　ジョブを足す

Universal Connect/X の「ジョブ」で、**動いているジョブをコピーして貼り付け**、増えた行を直します。

| 順 | 列 | 値 |
|---:|---|---|
| **1** | **対象** | **編集中は OFF** |
| 2 | Job ID | `JOB_ATOM_AT01` など |
| 3 | データファイル名 | `D:\SVFDATA\data_atom\AT01*.txt` |
| 4 | 実行様式名 | **様式のファイル名だけ**（パスを付けない） |
| 5 | 置換マスターファイル名 | **空** |
| 6 | ファイル定義 | **ファイル名だけ**（パスを付けない） |
| 7 | 出力先 | `PDF` |
| 8 | 文書分割 | ✓ |
| 9 | 出力ファイル名 | `D:\SVFDATA\PDF\ATOM\+?帳票区分+_+?ログインコード` |
| 10 | **対象** | **確認が済んだら ON** |

**「対象」が OFF だと、即時印刷でも動きません。**

> 検証したいときは、**「対象」を OFF にしたテスト用ジョブを併存させて手動実行**します。
> 既存システムでも `TEST_honma` `JOB003_test` のように同じやり方をしています。

### STEP 5　流して確かめる

1. 連携ファイルを `D:\SVFDATA\data_atom\` へ置く
2. ジョブを選んで「即時印刷」
3. PDF 出力先を見る
4. 出なければ左メニューの**「エラーログ」**を見る

## 6. 命名規約

### 接頭辞

既存（`C01` `CR1` `L01` `L02` `LR2` `P01…`）と重ならないものを使います。

| # | 帳票 | 帳票区分 | 接頭辞 |
|---:|---|---|---|
| 0 | 疎通確認用 | — | `AT00` |
| 1 | 配送手配書（定期便） | `TEIKI1` | `AT01` |
| 2 | 配送手配書（定期便2） | `TEIKI2` | `AT02` |
| 3 | 配送手配書（定期便3） | `TEIKI3` | `AT03` |
| 4 | 配送手配書（AIR） | `AIR` | `AT04` |
| 5 | 日新入荷 | `NISSHIN` | `AT05` |
| 6 | 入荷明細書 | `NYUKA` | `AT06` |

### ファイル名

```text
<接頭辞>_<REF_NO>_<yyyyMMdd>_<HHmmss>.txt
例: AT01_TY05-0001_20261019_142530.txt
```

投入する連携ファイルの名前は毎回変わります（`schema.ini` のセクション名は
ファイル定義の名前なので、データ側の名前は自由です）。
一方、**出力される PDF の名前は固定**です。両者を混同しないでください。

### PDF の出力先と名前

PDF 出力先は **`D:\SVFDATA\PDF\ATOM\` 1 つ**にまとめ、ファイル名で区別します。

```text
?帳票区分+_+?ログインコード
```

| 列 | 内容 |
|---|---|
| `帳票区分` | 帳票ごとに別名になる |
| `ログインコード` | 利用者ごとに別名になり、他人の出力と混ざらない |

**PDF 名は利用者と帳票で決まる固定名**です。日時は入れません。
「表示」ボタンがどのファイルを探せばよいかが一意に決まり、PDF も溜まりません。

**「出力ファイルの上書きを行う」が OFF のため、ATOM は出力の前に必ず既存の PDF を削除します。**
`%SYSTEMDATE%` は使いません。

## 7. ATOM 側の設定（Web.config）

| キー | 内容 |
|---|---|
| `Svf.WatchFolderPath` | 監視フォルダのパス（UNC） |
| `Svf.PdfFolderPath` | PDF の出力先フォルダのパス |
| `Svf.OutputPrinter` | 連携ファイルの `VrSetOutputPrinter` に書く論理プリンタ名 |

パスや出力先をコードに直書きしません。

## 9. うまくいかないとき

| 症状 | 原因 | 対応 |
|---|---|---|
| ジョブが動かない。別ジョブが「成功」と出る | 「対象」が OFF | ON にする |
| ファイルが拾われない | **`SVFDATA` と `SVFDATA_KH` の取り違え** | ジョブ一覧のパスに合わせる |
| `RC=[-4029]` CSVスキーマ情報が見つからない | ファイル定義と `schema.ini` がデータファイルと別のフォルダにある | **3 つを同じフォルダに揃える** |
| `RC=[-4029]` セクション名がデータファイル名で出る | ファイル定義が見つかっていない | ファイル定義欄を**ファイル名だけ**にする |
| `RC=[-30]` `VrSetForm` エラー | 様式が検索パスの外にある | **既存様式と同じフォルダへ置き、ファイル名だけで指定する** |
| PDF が出ない（エラーも出ない） | 「文書分割」と「出力ファイル名」が未設定 | 動いているジョブに合わせる |
| 日本語が化ける | 文字コードが CP932 でない／BOM が付いている | **CP932・BOM なし**で出力する |
| PDF が上書きされない | 「出力ファイルの上書きを行う」が OFF | **PDF 名を毎回ユニークにする**（設定は変えない） |

## 10. 注意

- **SVF サーバーは他システムの本番環境です。**既存のジョブ・様式・`schema.ini` を変更しないでください
- **監視間隔（15 秒）は全体の設定です。**ATOM の都合で短くしないでください
- 既存様式を開いたときは**保存せずに閉じて**ください
- 本リポジトリの `tools/svf/` のファイルは **CP932・BOM なし**です。`tools/Convert-ToUtf8Bom.ps1` の対象外にしてください
- サンプルに**実データを入れない**でください
