## 2. 画面概要
経費コードマスタ（`tbl_m_import_keihi_code`）を一覧形式で参照・追加・修正するマスタメンテナンス画面。SUB（明細一覧）がマスタに直接バインドされ、行を直接編集する。諸経費入力（menuNo=301）やメインメニューから呼び出される。

## 3. 起動条件・引数

| 引数 | 型 | 説明 | 現行の受渡し元 |
|---|---|---|---|
| login_code | string | ログイン社員コード | 共通ヘッダ（遷移元から複写） |
| return_form_name | string | 戻り先画面名 | form_open_close が設定 |

- 遷移元: メインメニュー（907）または 諸経費入力（F_3_輸入諸経費入力_MAIN）
- 起動時処理: `Form_Open` で `DoCmd.Maximize`（最大化）。SUBにフォーカスが入ると先頭レコードへ（`GoToRecord acFirst`）。

## 11. 移行メモ（Access → VB.NET / WinForms）

- **MAIN＋SUB → 1フォームに統合**：`ExpenseCodeMaintenanceForm` 上に `DataGridView` を配置し、SUB（一覧編集）を担う。
- **直接バインド**：`Atom.Data` の `SqlDataAdapter`＋`DataTable`（対象 `tbl_m_import_keihi_code`）を `BindingSource` 経由で `DataGridView` にバインド。更新は `SqlCommandBuilder` または明示的な更新SQL。
- **経費区分コンボ**：`DataGridViewComboBoxColumn` を `View__keihi_kbn` にバインド。
- **更新時スタンプ**：現行の各 AfterUpdate（update_ymd/update_login セット）は、`DataGridView.CellValueChanged` もしくは `DataTable.RowChanging` で `update_ymd=DateTime.Now`, `update_login=セッション社員コード` を設定して再現。
- **最大化**：`Me.WindowState = FormWindowState.Maximized`。
- **再接続**：`Login_ReInput` は共通セッション/再接続サービス（`Atom.App.Common`）に集約。
- **権限チェック**：起動時に共通基盤で menuNo=907 の管理者フラグを判定（現行 form_open_close 相当）。
- **戻り先制御**：`return_form_name` は画面遷移マネージャで保持し、閉じる時に復帰。
