# 2. 概要

ATOMシステム内の各画面上部に共通表示するヘッダー部品。

現行ATOM画面の以下の構成をASP.NET版でも共通部品として再現する。

```text
┌────┬────┬──────────────────────────────────────────────┬──────────────┐
│Icon│Icon│ ATOM （Arrangement of Tool Orders &          │ 使用者名     │
│    │    │ Materials System）Ver.4.0                   │              │
└────┴────┴──────────────────────────────────────────────┴──────────────┘
```

各業務画面側で個別にヘッダーHTMLを持たず、共通コンポーネント／共通レイアウトとして管理する。

# 8. ログインユーザー表示

ヘッダー右端に現在ATOMを使用しているログインユーザーを表示する。

添付画面表示例：

```text
使用者テスト用
```

ASP.NET版ではログイン処理で取得した社員情報を使用する。

基本表示値：

```text
login_name
```

表示例：

```text
使用者 山田太郎
```

または現行表示方式に合わせる場合：

```text
使用者山田太郎
```

最終的な接頭辞については現行画面仕様を優先する。

# 10. データ仕様

共通ヘッダーで使用するログイン情報は、ログイン成功時に保持した情報を利用する。

| 項目 | 内容 | 使用用途 |
|---|---|---|
| login_code | 社員コード | ユーザー識別 |
| login_name | 社員名 | ヘッダー表示 |
| bumon_code | 部門コード | 必要に応じた権限制御 |
| ATOM権限 | ATOM使用権限 | 必要に応じた表示制御 |

画面側から任意のユーザー名称を渡す方式ではなく、認証済みログイン情報から取得する。

---

# 11. 未ログイン時の扱い

共通ヘッダーを使用するATOM画面を未ログイン状態で表示しようとした場合、業務画面をそのまま表示しない。

```text
画面アクセス
    ↓
ログイン状態確認
    ↓
┌──────┴──────┐
│ログイン済み    │未ログイン
▼              ▼
画面表示        ログイン処理へ
```

共通レイアウトまたは共通認証フィルター等で制御し、各画面に個別実装しない。

---

# 12. レスポンシブ／表示幅

現行Access画面のデザインを基準とするが、ASP.NET版ではブラウザ画面幅に対応する。

### 基本方針

- ヘッダーは画面横幅100%とする。
- ATOMタイトル部分を中央の可変領域とする。
- ログインユーザー表示は右端固定とする。
- 画面幅が小さい場合でもログインユーザー表示がヘッダー外にはみ出さないよう制御する。
- 業務画面をスクロールした場合も、必要に応じてヘッダー固定表示が可能な構造とする。

---

# 13. 共通化方針

ASP.NET版では共通ヘッダーを1つの共通部品として実装する。

想定例：

```text
Shared Layout
    └── CommonHeader
```

または

```text
Master Layout
    └── ATOM Header Component
```

各画面は共通ヘッダーを参照し、個別に以下を保持しない。

- ATOMロゴ／タイトル
- バージョン表示
- ログインユーザー表示
- ヘッダー背景色
- 共通アイコン

これにより、ヘッダー変更時にATOM全画面を個別修正する必要がない構成とする。

---

# 14. 共通スタイル定義

CSS等で以下の色を共通変数として管理することを推奨する。

```css
--atom-header-bg: #400080;
--atom-header-text: #FFFFFF;
--atom-version-text: #FFFF00;
--atom-button-bg: #E1E1E1;
--atom-button-border: #ADADAD;
--atom-user-border: #000080;

--atom-menu-blue-bg: #99CCFF;
--atom-menu-pink-bg: #FF80FF;
--atom-menu-button-bg: #E1E1E1;
--atom-menu-border: #0000A0;
--atom-menu-blue-text: #0000A0;
```

画面側で直接HEX値を記述せず、ATOM共通スタイルとして一元管理する。

---

# 15. 備考

- ヘッダー背景色は添付画像より `#400080` を基準色とする。
- 現行画面の配色を可能な限り踏襲する。
- ログインユーザー名はログイン処理で取得した社員名を使用する。
- ATOMタイトル、バージョン、ユーザー表示は全ATOM画面共通とする。
- システムバージョン表示値を変更する場合、全画面を修正せず共通設定のみで変更可能な構造とする。
- 左側2アイコンの機能については今回提示仕様からは判断できないため、画面外観のみ現行仕様として定義し、押下処理は現行機能確認後に確定する。

| # | 確認内容 | 回答 | 反映箇所 |

| 1 | 画面名・背景色の扱い（既存は画面ごとに可変） | **メニュー画面は「ATOM」タイトル、それ以外の画面は画面名**を表示する。背景色も画面ごとに変える。画面別の設定は JSON 等の外部定義で持たせてよい | §3, §6, §7 |
| 2 | 既存ヘッダー右の「閉じる」ボタン | **不要**。ただし各遷移先画面の右上には、他画面への遷移ボタンやメニューへ戻るボタンを置く（各画面設計書で定義） | §5 |
| 3 | 利用者表示の接頭辞 | 「使用者」は**不要**。氏名のみ表示する | §8, §9 |
| 4 | バージョン値の管理場所 | `Web.config` に新設する。追加改修のたびにバージョンを更新する運用とする。開始値は `0.1.0` | §15 |
| 5 | 左側2アイコンの機能 | 左＝**再接続**、右＝**マニュアル**。両方とも配置する。マニュアルは別リンクを**新しいタブ**で開く（リンク先は未定。マニュアル用ページを作るか NotePM に切り出すかは今後相談。決まるまでは押下時に「現在未実装です。」を表示） | §5.1 |
| 6 | 再接続ボタンの Web での扱い | ASP.NET では DB 接続を処理ごとに開閉するため Access と同じ再接続は存在しない。**「画面の再読み込み」**に読み替えて実装する | §5.1 |
| 7 | フッター（既存の再接続ボタン・バージョン表示） | **フッターごと廃止**。バージョンはヘッダーのタイトル横に表示する | §2 |
| 8 | 未ログイン時の扱い | 共通処理（`BasePage`）でログイン状態を判定し、未ログインならログイン画面へリダイレクトする | §11 |
| 9 | 使用するログイン情報 | `login_code` / `login_name` / `bumon_code` / `login_mode_atom` / `shanghai_chotatsu` / `mail_address` を Session に保持する。ヘッダー表示に使うのは `login_name` のみ | §10 |

### 2026-08-14（実装内容の反映）

#### 画面固有ボタン領域を追加した（#2 の回答による）

ヘッダーの構成を次のとおりとした。左から順に並ぶ。

```text
┌────┬────┬───────────────────────────┬──────────────────┬──────────┐
│再読 │マニ│ ATOM タイトル または画面名 │ 画面固有ボタン    │ 利用者名 │
└────┴────┴───────────────────────────┴──────────────────┴──────────┘
```

- 画面固有ボタンは各画面が `BasePage.HeaderActions` へ追加する。件数は画面ごとに変わる
- 押下時は共通の画面遷移処理を通るため、**権限が無いとき・未実装のときの判定は画面側で書かなくてよい**
- メニュー番号 `0` を指定すると「メニュー画面へ戻る」になる
- ボタンを 1 つも追加しない画面では、この領域は何も表示しない

例（INVOICE/PACKING 取込画面）:

| 文言 | メニュー番号 | 遷移先 |
|---|---:|---|
| INVヘッダ | 103 | INVOICE ヘッダー入力画面（未実装のためメッセージ表示） |
| INV確認 | 102 | INVOICE 内容確認画面（未実装のためメッセージ表示） |
| MENUへ | 0 | メインメニュー画面 |

#### 実装した箇所

| 内容 | ファイル |
|---|---|
| ボタン 1 個分の定義 | `src/Atom.Web/Common/HeaderAction.vb` |
| 各画面からの登録先 | `src/Atom.Web/Common/BasePage.vb` の `HeaderActions` |
| 描画と押下時の処理 | `src/Atom.Web/Controls/HeaderControl.ascx`（`.vb` / `.designer.vb`） |
| 見た目 | `src/Atom.Web/Content/site.css` の `.atom-header-action` |

#### 補足（§14 共通スタイル定義について）

Visual Studio のデザイナは **CSS 変数と Flexbox / Grid を解釈できない**ため、
共通変数を使ったスタイルはデザイナのプレビューに反映されない。
見た目の確認はブラウザで行う。共通変数による一元管理は §14 のとおり維持する。
