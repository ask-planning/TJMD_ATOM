# コーディング規約（VB.NET / WinForms / .NET Framework 4.8.1）

文書ID: C4_コーディング規約　／　版: 0.1　／　対象: ATOM リプレイス `src/` 全プロジェクト

本規約は決定事項に基づく。既存コードで未準拠の箇所は末尾「9. 既存コードの是正項目」を参照。

---

## 1. 適用範囲・前提
- 対象は `src/` 配下の全 VB.NET コード（Atom.App / Core / Data / Mail / Report）。
- 自動生成ファイル（`*.Designer.vb`、`My Project/*`）は対象外。

## 2. コンパイラオプション（プロジェクト設定）
| オプション | 値 |
|---|---|
| Option Strict | **On** |
| Option Explicit | **On** |
| Option Infer | **Off**（ローカルは型を明示するため） |
| Option Compare | Binary |

`Dim` は必ず型を明示する（型推論に依存しない）。

```vb
' NG
Dim conn = Database.CreateConnection()
' OK
Dim conn As SqlConnection = Database.CreateConnection()
```

## 3. 命名規約

| 対象 | 規則 | 例 |
|---|---|---|
| 名前空間 | PascalCase | `Atom.App.Forms.Expense` |
| クラス / 構造体 / モジュール | PascalCase | `ExpenseCodeRepository` |
| フォーム | PascalCase＋`Form` 接尾 | `ExpenseCodeMaintenanceForm` |
| メソッド / プロパティ / イベント | PascalCase（頭大文字キャメルケース） | `SelectAll`, `ScreenTitle` |
| 定数（Const / Shared ReadOnly） | **PascalCase** | `SelectAllSql`, `MaxRetryCount` |
| プライベートフィールド | **`_camelCase`（先頭アンダースコア）** | `_repo`, `_table` |
| ローカル変数 / 引数 | camelCase（**頭小文字**） | `loginCode`, `menuNo` |
| Boolean | `Is` / `Has` / `Can` 接頭 | `IsAllowed`, `HasError` |
| Enum 型 / メンバー | PascalCase | `ShanghaiChotatsu.Shanghai` |

- **メソッドは頭大文字のキャメルケース（PascalCase）**、**変数・引数は頭小文字のキャメルケース**。
- **難しい英単語は使わない。** 誰でも分かる簡単で一般的な語を選ぶ（例: `Retrieve`/`Fetch` より `Get`、`Terminate` より `Close`、`Aggregate` より `Sum`）。適語がなければ日本語ローマ字も可（例: `keihiCode`）。

### 3.2 クエリ実行メソッドの命名
DBへクエリを発行するメソッドは、**先頭にクエリ種別（`Select` / `Insert` / `Update` / `Delete`）**を付け、その後に対象を続ける（頭大文字キャメルケース）。

| 用途 | 例 |
|---|---|
| 取得 | `SelectAll`, `SelectByCode` |
| 追加 | `InsertExpenseCode` |
| 更新 | `UpdateExpenseCode` |
| 削除 | `DeleteExpenseCode` |

※ DBを伴わない一般メソッドは通常の動詞（`Build…`, `Show…` 等）でよい。


### 3.1 WinForms コントロールの命名（プレフィックス方式）
コントロールは**プレフィックス方式**とし、フィールドであっても**アンダースコアは付けない**（`_dgvList` ではなく `dgvList`）。

| コントロール | 接頭 | コントロール | 接頭 |
|---|---|---|---|
| Button | `btn` | DataGridView | `dgv` |
| Label | `lbl` | ComboBox | `cmb` |
| TextBox | `txt` | CheckBox | `chk` |
| RadioButton | `rdo` | Panel | `pnl` |
| GroupBox | `grp` | TabControl | `tab` |
| DateTimePicker | `dtp` | ListBox | `lst` |
| PictureBox | `pic` | BindingSource | `bs` |
| Timer | `tmr` | StatusStrip | `ss` |
| MenuStrip | `ms` | ToolStrip | `ts` |

例: `btnSave`, `dgvList`, `cmbKbn`, `lblTitle`, `bsExpense`

## 4. コメント / ドキュメント
- コメントは**日本語**で記述する。
- **すべての Public 要素**（クラス・メソッド・プロパティ・イベント）に **XMLドキュメントコメント（`''' <summary>`）を必須**とする。日本語で記述。
- **1処理ごとに説明コメントを付ける。** メソッド内の各処理ブロック（取得・表示・切替・登録・分岐など）の先頭に、その処理が何をするかを1行で書く。
- **条件分岐は分岐ごとの意味を書く**（「Aのとき○○、Bのとき○○」の形）。
- 難しい英単語・専門用語は避け、簡単な日本語で書く。

```vb
' 経費コード一覧の取得・表示
Dim table As DataTable = Me._repo.SelectAll()
Me.bsExpense.DataSource = table

' 明細の表示・非表示を切り替える
Me.dgvList.Visible = isDetailMode

' 区分により表示を切り替える（運賃のとき単価欄、諸掛のとき金額欄）
If kbn = "運賃" Then
    ' 運賃のとき：単価欄を表示
    Me.txtUnitPrice.Visible = True
Else
    ' 諸掛のとき：金額欄を表示
    Me.txtAmount.Visible = True
End If
```

XMLドキュメントコメントの例:

```vb
''' <summary>経費コードマスタを全件取得する。</summary>
''' <returns>画面表示用の一覧（DataTable）。</returns>
Public Function SelectAll() As DataTable
```

## 5. レイアウト / 記述スタイル
- **1ファイル1型**（ファイル名＝型名）。
- **`#Region` を使用**し、メンバー種別で区切る。推奨順序:
  `定数` → `フィールド` → `コンストラクター` → `プロパティ` → `公開メソッド` → `イベントハンドラー` → `内部メソッド`
- **インスタンスメンバーは常に `Me.` を付ける**。
- **アクセス修飾子は常に明示**（`Public` / `Private` / `Friend` / `Protected` を省略しない）。
- インデントは半角スペース4（VB既定）。1行はおおむね120桁を上限の目安。
- 文字列連結は **`&`** を使う（`+` は使わない）。
- 文字コードは UTF-8。
- **画面タイトル・固定UI文字列はフォームにべた書きしない。** リソース（`.resx`）に定義する。画面タイトルは `Resources\ScreenTitles.resx`（キー=menuNo）に持たせ、`BaseForm` が `MenuNo` から自動解決する。フォーム側は `MenuNo` の設定のみ。

```vb
#Region "フィールド"
    Private ReadOnly _repo As ExpenseCodeRepository
#End Region
```

## 6. 例外処理・ログ
- **各層で Try-Catch** を行い、握りつぶさない。
- **UI 層でユーザーへ通知**（`MessageBox`）し、**ログを記録**する。
- ログは **SQL Server のログに記録**（現行「処理ログ」を踏襲）。共通のログ出力口（`Atom.Data` のログ用メソッド／ストアド）に集約する。
- 例外は握って `Return` で無かったことにしない。想定外は上位へ再スロー可（`Throw`）。

```vb
Try
    Me._repo.Save(Me._table)
Catch ex As Exception
    Logger.Write("経費コード保存に失敗", ex)          ' SQL Serverログへ
    MessageBox.Show("保存に失敗しました。" & vbCrLf & ex.Message,
                    "保存", MessageBoxButtons.OK, MessageBoxIcon.Error)
End Try
```

## 7. データアクセス（既定方針の再掲）
- SQL は **`Atom.Data` に集約**（UI/画面に SQL を書かない）。
- ストアド呼び出しは `StoredProcedures/`、べた書きSQLは `Repositories/` にインライン統一。
- 値は必ず **`SqlParameter`** 化（文字列連結でのSQL組み立て禁止）。
- 動的なテーブル名は**ホワイトリスト検証**を通す。
- SQL Server 側のストアド（`usp_*`）・テーブル・ビューは**現状維持の契約**として変更しない。

## 8. 規約準拠サンプル
```vb
Imports System.Data
Imports System.Data.SqlClient

Namespace Repositories
    ''' <summary>経費コードマスタ（tbl_m_import_keihi_code）のデータアクセス。</summary>
    Public Class ExpenseCodeRepository

#Region "定数"
        Private Shared ReadOnly SelectAllSql As String =
            "SELECT pk_keihi_code, keihi_code_text FROM tbl_m_import_keihi_code ORDER BY pk_keihi_code"
#End Region

#Region "公開メソッド"
        ''' <summary>経費コードマスタを全件取得する。</summary>
        ''' <returns>画面表示用の一覧（DataTable）。</returns>
        Public Function SelectAll() As DataTable
            Dim table As New DataTable()
            ' 接続を開いて一覧を取得する
            Using conn As SqlConnection = Database.CreateConnection()
                Using adapter As New SqlDataAdapter(SelectAllSql, conn)
                    adapter.Fill(table)
                End Using
            End Using
            Return table
        End Function
#End Region

    End Class
End Namespace
```

## 9. 既存コードの是正項目（規約適用時）
1. **Option Infer を Off** にし、`Dim x = …` の型推論を型明示へ修正（`SessionContext`／接続取得／`menuNo` 等）。
2. **コントロールのフィールド名を改名**（アンダースコア除去＋プレフィックス）:
   `_grid`→`dgvList`、`_header`→`hdrHeader`、`_footer`→`pnlFooter`、`_btnClose`→`btnClose`、`_btnReconnect`→`btnReconnect`、`_bs`→`bsExpense`、`_login/_name/_dept/_title`→`lbl…`
3. 各クラスへ **`#Region`** をメンバー種別で付与。
4. インスタンスメンバーへ **`Me.`** を付与。
5. すべての **Public 要素へ XMLドキュメントコメント** を付与（未付与箇所を補完）。
6. アクセス修飾子の**明示**を徹底。
7. 例外処理を各層に整備し、**SQL Serverログ**への記録口（`Logger`／処理ログ）を用意。
8. **クエリ実行メソッドを改名**（`ExpenseCodeRepository.GetAll` → `SelectAll` 等、`Select/Insert/Update/Delete` 接頭へ）。
9. 各処理ブロックへ **1処理ごとの説明コメント** を追記（条件分岐は「Aのとき／Bのとき」で明記）。
