# ATOM リプレイス — ドキュメント体系・フォルダ構成 定義書

版: 0.1（ドラフト）　対象: ATOM.adp 赤枠4ブロック（17メニュー）の VB.NET + SVF 移行

---

## 0. 前提

| 区分 | 決定/前提 | 備考 |
|---|---|---|
| 移行元 | Microsoft Access 2003 プロジェクト (.adp) | 画面/帳票/VBAのみ。データとロジックはSQL Server側 |
| 移行先UI | **VB.NET / WinForms**（確定） | Access画面の1:1移行に適する |
| .NET | **確定: .NET Framework 4.8.1** | SVF Client（旧 SVF for .NET Framework）がネイティブ対応＝互換性確認済み。長期サポート（OS寿命に紐づき事実上無期限）。**.NET 8/9 は2026-11-10 EOSのため不可** |
| 帳票 | **SVF**（確定）：設計=**SVFX-Designer** ／ 実行時出力=**SVF Client**（旧 SVF for .NET Framework） | 既存レポート18本を移行。設計と実行時モジュールを区別 |
| DB | **SQL Server（現状維持）** | ストアド93本はVB.NETから同名で呼び出す |
| メール | **.NETで再実装** | 現行はBASP21(COM)＋共有フォルダExcel出力 |
| 文書形式 | **Markdown / Excel の2形式**（確定。Wordは不要） | 種類別に使い分け（第0.1節） |

基盤技術はすべて確定しました（WinForms ／ .NET Framework 4.8.1 ／ SVF）。`src` 構成を確定します。

### 0.1 文書フォーマット方針（2形式の使い分け）

単一の元データ（Markdown）を正とし、一覧・台帳のみ Excel を用います（Wordは使用しない）。

| 文書タイプ | 形式 | 理由 |
|---|---|---|
| 方針書・基本設計・画面設計書（説明文中心） | Markdown | Gitで差分管理しやすい |
| 一覧・台帳（棚卸し/スコープ/IF/帳票一覧） | Excel | フィルタ・並べ替え・集計に適する |
| 全文書の索引・管理表 | Markdown | － |

※ 一覧系（棚卸し・スコープ定義）は既にExcelで作成済み。説明文中心の文書はMarkdownで作成（Git管理）。

## 3. フォルダ構成（VB.NET ソリューション）※WinForms／.NET Framework 4.8.1（確定）

レイヤ分割し、UI（WinForms）と データアクセス（ストアド呼出）と メール/帳票 を分離します。

```
src/
└─ Atom.sln
   ├─ Atom.App/                 # 起動・画面（WinForms）
   │  ├─ Program.vb
   │  ├─ Common/                # BaseForm, ナビゲーション, 権限, セッション
   │  ├─ Forms/
   │  │  ├─ ShanghaiImport/     # 上海輸入INVOICE（取込/確認/ヘッダー/明細）
   │  │  ├─ PurchaseOrder/      # R3購買発注・在庫転送・SAP金額
   │  │  ├─ ImportCheck/        # 取込内容確認（+4サブ）
   │  │  ├─ Procurement/        # 調達輸入 配送手配書
   │  │  ├─ Expense/            # 諸経費入力
   │  │  ├─ Master/             # 項目/カレンダー/仕入先/商品名称/経費コード/参照番号
   │  │  └─ Mail/               # メール送信画面
   │  └─ Reports/               # SVF呼び出しラッパ（画面→帳票）
   ├─ Atom.Core/                # 定数, DTO, enum(ShanghaiChotatsu等), 共通ロジック(丸め等)
   ├─ Atom.Data/                # SQL Server境界（UIにSQLを置かない。SQLはこの層に集約）
   │  ├─ StoredProcedures/      #   usp_* 呼出ラッパ（現状維持の契約）
   │  ├─ Repositories/          #   べた書きSQL（実行/バインド用）をクラス内にインライン統一。値はSqlParameter化
   │  └─ TableGateways/         #   直接バインド系マスタの入出力
   ├─ Atom.Mail/                # メール送信（BASP21代替: System.Net.Mail 等）
   ├─ Atom.Report/              # SVF出力基盤（SVF Client=旧SVF for .NET Framework を参照）
   └─ Atom.Tests/               # 単体テスト
```

### 3.2 命名規約（コード）
- 名前空間: `Atom.App.Forms.<領域>`（例 `Atom.App.Forms.ShanghaiImport`）
- クラス名: 英語 PascalCase（例 `F_1_上海輸入_INVOICE取込` → `ShanghaiInvoiceImportForm`）。日本語→英語の対応表を `03_基本設計/命名対応表` に集約。
- ストアド呼出: `Atom.Data` に `usp_*` 1本＝1メソッドのラッパ（引数はSQL Server定義に合わせる）。名称・引数は**変更しない**（現状維持の契約）。
- 上海/調達の共用: `ShanghaiChotatsu`（enum: Shanghai=1, Chotatsu=2）を画面生成時に渡し、現行 `shanghai_chotatsu` フラグの分岐を踏襲。

## 4. 設計書テンプレート（雛形に用意する項目）

### D-1 画面設計書（1画面1シート/1ファイル）
1. 画面ID・名称・対応現行フォーム・所属ブロック
2. 起動条件・パラメータ（例: INVOICE_NO, ShanghaiChotatsu）
3. 画面項目一覧（項目名・型・入出力・必須・初期値・元VBAコントロール名）
4. イベント一覧（ロード/ボタン/変更 → 処理内容 → 呼出ストアド）
5. 呼出ストアド（名称・引数・用途）※スコープ定義書04シートを転記
6. バリデーション/権限（管理者権限チェック有無）
7. 帳票・メール連携（あれば）
8. 画面遷移（前後）

### D-2 帳票設計書（SVF）
帳票ID・対応現行レポート・用紙/様式・データ源（SP/ビュー）・出力条件・パラメータ

### D-3 ストアドIF一覧
SP名・区分・引数（IN/OUT・型）・戻りセット・呼出画面 ※引数はDB定義参照で補完
