### 配送手配書（27 列）

| ファイル | 用途 |
|---|---|
| `定義AT01配送手配書.txt` | ジョブの**「ファイル定義」**。**AT01〜AT03 で共有する** |
| `AT01_TEST-0001_…txt` | 定期便。配送先 1 箇所だけ埋めたもの |
| `AT01_TEST-0002_…txt` | 定期便。**長い配送先名**を入れて切れ方を見るもの |
| `AT02_TEST-0003_…txt` | **定期便2。配送先 1・2 を埋め、3 は空** |
| `AT03_TEST-0004_…txt` | **定期便3。配送先 1〜3 をすべて埋める** |

**3 つの様式はすべて同じ 27 列**を受け取る。違うのは様式に置く枠の数だけで、
様式に無い列は無視される（エラーにならない）。`帳票区分` は `TEIKI` / `TEIKI2` / `TEIKI3`。

**Shift_JIS（CP932）／CRLF／BOM なし／タブ区切り。**

> **このフォルダのファイルに BOM を付けないこと。**
> `tools/Convert-ToUtf8Bom.ps1` の対象外。SVF が読めなくなる。

## 手順

### STEP 1　書き込めるか

ATOM を動かす Web サーバーから、SVF サーバーの投入フォルダへファイルを置けるか確かめる。

1. `\\（SVFサーバー）\SVFDATA\data\` を開く
2. 適当なテキストファイルを置く（**`zztest.txt` など、既存の接頭辞と重ならない名前**）
3. 置けたら消す

置けなければ、共有の公開と書き込み権限の設定が要る。

### STEP 2　様式を作る（最小）

SVFX-Designer で**白紙に文字枠を 2 つ置くだけ**の様式を作る。

| フィールド名 | 内容 |
|---|---|
| `REF_NO` | 文字枠 |
| `MEMO` | 文字枠。**日本語が出るフォント**に |

罫線もタイトルも要らない。**名前が見出し行と一致していることだけが重要。**

**保存先は既存様式と同じフォルダ。**新しいフォルダに置くと、ジョブでフルパス指定しても
`VrSetForm` が `RC=[-30]` で開けない。新規ファイルを 1 つ足すだけなので既存には影響しない。

### STEP 3　ジョブを 1 つ足す

既存の `JOB_L01P` を**コピーして直す**のが早い。

| 設定 | 値 |
|---|---|
| Job ID | `JOB_ATOM_TEST` |
| データファイル名 | `D:\SVFDATA\data\AT00*.txt` |
| 実行様式名 | **STEP 2 の様式のフルパス** |
| 置換マスターファイル名 | **空** |
| ファイル定義 | `定義AT00接続テスト.txt`（SVF サーバーへ置いて指定） |
| 出力先 | `PDF` |
| 文書分割 | **OFF** |
| 出力ファイル名 | PDF の出力先フォルダとファイル名 |
| 対象 | **OFF**（手動実行で試す） |

### STEP 4　流す

1. `AT00_TEST-0001_20260101_120000.txt` を `D:\SVFDATA\data_atom\` へ置く
2. **手動実行（即時印刷）**
3. PDF ができるか見る。出なければ**エラーログ**

### STEP 5　記録すること

- [ ] PDF が出たか
- [ ] PDF の**ファイル名**
- [ ] 投入した txt が**どうなったか**（消える／移動／残る）
- [ ] 投入から PDF まで**何秒か**
- [ ] 日本語が化けていないか

## つまずいた点（2026-10-19）

| # | 症状 | 原因 |
|---:|---|---|
| 1 | ジョブが動かない（別ジョブが「成功」と出る） | 「対象」が OFF |
| 2 | ファイルが拾われない | **`SVFDATA` と `SVFDATA_KH` の取り違え。**2 系統ある |
| 3 | `RC=[-4029]` CSVスキーマ情報が見つからない | ファイル定義と `schema.ini` が投入フォルダと別の場所にあった |
| 4 | `RC=[-30]` `VrSetForm` エラー | 様式を新設フォルダに置き、フルパスで指定した |

## 注意

- **SVF サーバーは他システムの本番環境。**既存のジョブ・様式には触れない
- 新しいジョブは**「対象」OFF で足して手動実行**する
- サンプルに**実データを入れない。**値は `TEST…` / `テスト…` のダミーとする
